# Actividad Integradora 1 — Portafolio Web Académico

Este repositorio contiene la entrega oficial de la **Actividad Integradora 1** para la asignatura de **Programación Web** en la **Universidad ECOTEC**.

El proyecto consiste en el diseño, maquetación y despliegue de un portafolio web funcional desarrollado mediante HTML5 semántico y CSS3, cumpliendo con los criterios de evaluación e integrando enlaces a proyectos reales de automatización de calidad de software (QA).

## 📁 Estructura del Proyecto Académico

- **`index.html`**: Estructura HTML5 semántica del portafolio (secciones de Inicio, Sobre Mí, Habilidades, Proyectos y Contacto).
- **`styles.css`**: Estilos CSS3 con diseño responsivo (*Responsive Design*), variables y maquetación tipo tarjeta (*Card UI*).
- **`img/`**: Carpeta de imágenes y evidencias de proyectos (`proyecto1.png`, `proyecto2.png`).
- **`README.md`**: Documentación oficial del entregable universitario.

## 📌 Requisitos y Estándares de Entrega

- **HTML5 Semántico**: Uso estructurado de etiquetas como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **CSS3 Moderno**: Implementación de Flexbox, CSS Grid y adaptabilidad para pantallas móviles.
- **Conventional Commits**: Historial de control de versiones con mensajes estandarizados (`feat`, `style`, `fix`, `docs`).
